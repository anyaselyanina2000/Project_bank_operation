# Проект "Банковская операция"

## Описание:

Проект "Банковская операция" - это приложение на Python, которое показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:anyaselyanina2000/Project_bank_operation.git
```

2. Установите зависимости:
```
poetry install
```

## Тестирование:
Для тестирования используется библиотека pytest. Тесты находятся в директории tests.

## Модуль generators:
Модуль generators содержит функции для работы с массивами транзакций, используя генераторы для эффективной обработки данных.
